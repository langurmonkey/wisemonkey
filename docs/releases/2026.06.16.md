## Features

- Multi-API router with native support for OpenAI, Anthropic, Ollama, LM Studio, and any OpenAI-compatible endpoint.
- MCP integration -- run MCP servers over stdio and register tools dynamically at runtime.
- AGENTS.md and configurable workspace context files.
- `find_files` and `search_content` tools (replacements for `find` and `grep`).
- Update system moved to `agent/update.py` with global metadata at `~/.config/wisemonkey/.updates.yml`.
- `--onboard` flag for interactive first-run configuration.
- Timestamps and exchange counts in `/session-chat`.
- Pretty time deltas (e.g. "2 hours ago").
- Badges and banners in README and startup output.
- `justfile` for convenience commands (run, test, build).

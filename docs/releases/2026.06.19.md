## Features

- Experimental full-screen TUI built with Textual (activate with `--tui`); a first prompt_toolkit-based attempt was reverted in favor of it.
- `create-plan` skill added.
- Startup sequence extracted to its own module (`agent/startup.py`).
- Sessions sorted by recently used in `-ls` listing.
- `session` argument moved to a positional argument and made optional.
- `uvx` installation method documented in the README.

## Fixes

- Interrupting (Ctrl+C) during the initial phase (between `router.chat` and the first chunk) no longer crashes the agent.

## Other

- Unused import removed, comments added to the startup module.

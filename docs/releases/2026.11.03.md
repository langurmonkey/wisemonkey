## Features

- **Full markdown streaming:** the streamed renderer now handles the constructs it used to leave raw. Tables are laid out to the console width with alignment taken from the delimiter row; fenced code blocks are highlighted with a theme derived from the palette rather than a named Pygments theme; setext headings (`Text` underlined with `---` / `===`) are recognised; and backslash escapes, images, task lists and fences opened with three or more backticks or tildes all render correctly. Horizontal rules now span the full terminal width and are drawn in a dim grey.
- **Ruler between tool output and the answer:** a faint full-width divider is drawn when the model starts speaking again after a tool ran, so the answer is no longer visually glued to the tool log above it.
- **Command categories:** `/help` groups commands under headings (`General`, `Config`, `Session`, `History`, `Planning`, `Embedding & Images`, `Tools & Skills`, `MCP`) instead of printing one flat list. `/help` is pinned first in its group; commands are alphabetical within the rest. `/connect` is added as an alias for `/model`.
- **Endpoint setup from `/model`:** the command now configures the whole endpoint -- URL, provider, API key variable and model name -- in one flow, so nothing needs to be edited in `.env` by hand. A list of usual endpoints is offered, and the key step is a choice list that marks the variables already set in the environment.
- **Plan listing:** `/plan-list` (and the `list_session_plans` tool) sort active plans to the top, shown in green with a bold name, while finished and obsolete plans recede in grey. The summary line now reports how many plans are active.
- **Steering input line:** the footer's steering row renders a prompt marker and a block cursor even when empty, and supports real line editing -- caret movement by character and by word, Home/End, Backspace/Delete, `Ctrl+K` and `Ctrl+U` -- with the line scrolled so the caret stays visible. A partial line survives a tool asking for confirmation or handing the terminal to a subprocess, and a line the turn never consumed is placed in the next prompt as editable text instead of auto-submitted.
- **Safer memory writes:** memory files (`chat_history.json`, `notes.json`, `user_profile.json`) are written atomically, and a corrupt file is quarantined instead of silently reset or crashing the session.
- **Reasoning effort resilience:** a 400 that names the effort parameter (gateways that translate `reasoning_effort` into a narrower vocabulary, e.g. Logfare -> Anthropic `output_config.effort`) is retried once without it. Logfare has a default API key variable.
- **Narrower exception handlers** in `memory`, `tokens`, `skills` and `utils`, so a failure is reported instead of swallowed.

## Fixes

- **Session metadata permissions:** only `pasted/` and `tmp/` inside the current session directory are reachable without confirmation. Plans, notes, profile, chat history and the vector store remain behind their own tools, and another session's directory is always outside. Previously the whole session directory was open, which made the guard on agent state meaningless.
- **Intermittent 400 in DeepSeek thinking mode**, caused by `reasoning_content` being sent on every assistant message rather than the ones that carry it.
- **`/retry`** not working properly.
- **Steering lines submitted near the end of a turn** were sent through after the turn finished, silently starting a new one; they now populate the prompt for the user to edit or submit.
- **TUI removed** -- the deprecated interface is gone, together with the code paths that only existed to serve it.

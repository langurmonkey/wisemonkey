## Features

- `/markdown` command to configure markdown rendering; markdown functionality restored.
- Confirmation prompt when the agent tries to search for files outside the current working directory.
- Skills are also loaded from `./skills` in the current working directory (in addition to the wisemonkey skills directory).
- `agent.unsafe` config flag and `/unsafe` command: disable confirmation prompts for dangerous commands.
- `web_search` tool -- queries DuckDuckGo's HTML endpoint and parses the results.
- MCP servers can now connect over HTTP and Streamable HTTP (`http`, `streamable-http`, `sse`), in addition to stdio.
- Full conversation persistence: tool calls and intermediate assistant turns are now stored in chat history, not just the final turns. Two new config options control it: `agent.chat_history_full_tool_results` and `chat_history_tool_result_max_chars` (truncate tool results when the former is `false`).
- Session plan tools report progress when saving plans.
- Clearer error messages in the file tools (missing path, path does not exist, not a file/directory, missing `old_string`/`pattern`).

## Fixes

- `find_files` no longer asks for permission when the target is the current working directory itself (proper `samefile` equivalence check).
- Markdown formatting is no longer shown when a turn was cancelled.
- Auto-compaction invoked the wrong internal command (`/session-compact` -> `/session-chat-compact`).
- Incorrect `HTTP-Referer` URL in router request headers.
- Fixed tool printouts.

## Other

- Tool-call arguments now formatted into a compact, human-readable string in the output (`format_tool_args`).
- Stray debug printouts removed.
- Version bump and lock file updates.

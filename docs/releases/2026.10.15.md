## Features

- **External tool hooks:** guard programs run around every tool call -- REPL and daemon mode, MCP tools included -- using the Claude Code / Codex hook protocol, so `dcg` and any existing Claude hook script work unchanged. A `pre_tool_use` hook may `allow`, `ask` or `deny`; a block is shown as a framed panel attributed to the hook, clearly distinct from an agent-reported tool failure. Configured under `agent.hooks` in `config.yaml`, with `matcher`, `timeout`, `fail_open` and `honor_unsafe` per handler.
- **Container support:** new `wmkc` wrapper and `Dockerfile` run the agent in Docker, so no Python or `uv` is needed on the host. The container runs as the calling user -- not root -- and bind-mounts only the workspace, the config directory and the data directory, so written files stay owned by you and sessions survive the container. `install.sh` installs `wmkc` when Docker is present.
- **Per-session configuration:** a session first looks for `<session_dir>/config.yaml` and falls back to the global config, so individual sessions can diverge without affecting the rest.
- **API key management:** an ordered per-provider resolution chain (`model.api_key_env` -> `WM_API_KEY_<PROVIDER>` -> the provider's conventional variable -> `WM_API_KEY`), so several router/endpoint keys coexist without being rewritten on every provider switch. `/model` and `/url` now configure the whole endpoint (URL -> provider -> key -> model) in a single flow.
- **Broader confirmation policy:** the agent now asks before network tools (`fetch_url`, `web_search`) and before operating on paths outside the session working directory. `agent.unsafe` / `/unsafe` still skips all confirmations.
- **Live token counter and cost:** the status line shows token usage as a delta after every turn, together with the per-turn cost when `model.pricing` is configured (omitted otherwise, never guessed).
- **`read_image` tool:** the model can read an image from disk; the `screenshot` and `read_image` tools are now consolidated in `tools/images.py`.
- **History commands:** new `/history-info`; `/history [n]` now takes a number of turns rather than messages; `/history-compact [n]` can summarize just the n oldest exchanges.
- **`patch_file` diffs:** file edits now print a coloured diff of what changed.
- **Reasoning effort:** `model.thinking.effort` gains `minimal`, `xhigh` and `max`, and each provider (OpenAI/generic, Ollama, Anthropic) translates the level to its own dialect.
- **Command help:** command examples are separated from their one-line descriptions.
- **Startup banner** improved in banner-less mode.

## Fixes

- **Readline prompts:** confirmation and input prompts now hand readline the real prompt, so arrow keys no longer type ANSI escape codes into the line and Backspace no longer erases the question. `rich.prompt` prompts also drop the kitty keyboard protocol for their duration.
- **Incomplete streams:** a stream that ends without the provider's terminal `finish_reason` (a dropped connection) or at the output-token budget (`length`) is now flagged and warned about, marked in the stored exchange and shown as `(continued)` in the startup recap, instead of being silently persisted as a complete answer.
- **Bottom of the prompt eaten** by the first lines of LLM output -- fixed.
- **'Prompt processed' redundant message** removed; live token reporting fixed.
- **Malformed tool arguments** (a truncated or invalid JSON `arguments` string) are now a tool error the model can recover from, never a crashed turn.
- **Crash during inference** fixed.
- **Empty `chunk.choices`** guard added, so a usage-bearing chunk no longer drops a delta that shares it.
- **Reasoning effort** issue with the router fixed.
- **Thinking output** errors fixed.
- **Thinking colour** separated from `faint`, so reasoning no longer competes visually with the answer.
- **Incorrect function name** in the compact operation fixed.
- **`x-opencode-session`** header added when calling the OpenCode API endpoint.
- **Tool printouts** moved into the status bar and tidied up.

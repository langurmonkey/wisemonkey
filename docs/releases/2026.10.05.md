## Features

- **Chat archive:** trimmed chat exchanges are no longer lost. Both `_trim_to_window()` (rolling window) and `_trim()` (token cap) append dropped entries to `chat_archive.jsonl` in the session directory. The file is append-only, never read back into context, and write failures are swallowed — it exists purely so no user data is lost.
- **Mid-turn steering:** submit text while a turn is running. Keystrokes are collected on a daemon thread and injected at tool-call seams (or between turns). Typed input goes through the same `@`-expansion, command dispatch and turn path as a normal prompt. Disabled with `agent.steer_midturn: false`.
- **Sticky footer with spinner:** a persistent status line at the bottom of the REPL during turns (model, session, memory usage), animated with its own braille spinner for stage labels. Drawn via ANSI scroll regions (`DECSTBM`) so it stays pinned while output streams.
- **Turn cancellation hint:** `Ctrl+C: Cancel turn` printed at the top of each assistant turn.
- **One-shot mode:** `-p`/`--prompt` CLI argument runs a single prompt without startup banner or summary.
- **Markdown streaming renderer:** new `mdstream.py` module renders streamed markdown following the console theme. Enabled by default via `agent.markdown_stream`; `agent.markdown` still works as a fallback. Token accounting fixed for both modes.
- **Session management commands:** `/sessions` and `/resume <session>` list sessions and resume them (local mode only). Renamed `/session plan` → `/plan`, `/session chat` → `/history`.
- **Edit/retry/undo:** `/edit` opens the last user prompt in `$EDITOR` on a temp file and replaces the exchange; `/retry --drop` re-runs from a clean context; `/undo` drops the last exchange. Commands are filtered out of up-arrow history.
- **Injection message clears:** submitted steering lines are removed from the footer input row after delivery.
- **Recap counts Q/A turns:** startup recap tallies actual question/answer turns instead of raw history entries.

## Fixes

- **Assistant header disappearing:** the "Wisemonkey ⇒ model" line was erased intermittently when the screen was already full, because the header was printed *before* `footer_start()` which blanks the bottom rows. Fixed by arming the footer first.
- **Prompt unresponsive after external editor:** `/edit` and similar commands that hand the terminal to a subprocess left the reader in a bad state. Fixed by properly tearing down and restoring the scroll region and steer reader around subprocess calls.
- **Double blank lines** removed from output.
- **Tool results reporting:** only report tool results that say something (silent tools no longer emit noise).
- **Crash cancelling mid-tool-call:** cancelling a turn while blocked inside a tool no longer crashes the agent.
- **Startup crash** on certain configurations.
- **Footer key bold** styling issue.
- **Key mapping regression** affecting cursor keys and other special keys.

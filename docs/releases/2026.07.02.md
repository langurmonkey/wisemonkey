## Features

- Big refactor unifying all output methods into a single `OutputAdapter` per mode (TUI/CLI) — replaced the old `prompt_ui` module and fixed most output-related problems.
- Turn cancellation in the TUI (bound to `Ctrl+S`).
- Autocompletion for slash commands and file system paths in the REPL.
- `ask_choice()` now uses autocompletion for its options.
- Bind `Ctrl+O` to open the chat in `$PAGER`.
- Skills restructured to the agentskills format (directory with `SKILL.md`): new `code-review` and `readme-gen` skills, `create-plan` converted; skills for code review, plan creation, and README generation.
- Session plan tools and slash commands: `/session-plan`, `/session-plan-read`, `/session-plan-edit`, plus plan management tools in `tools/memory.py`.
- `get_session_info` tool (session name and working directory); improved default system prompt.
- `/attachimage` slash command to attach an image to the next prompt.
- `screenshot` tool — the model can take screenshots of the user's screen (guarded by user confirmation).
- Thinking (reasoning) and prompt stage callbacks for streaming progress.
- Session name shown in the REPL prompt.
- Input history and tracked pasted files in the TUI.
- `find_files` output now prints the searched pattern.
- Slash commands reorganized (e.g. `/session clear [N]`, `/session-chat-clear`, `/session-chat-compact`).

## Fixes

- Editing in-place with `$EDITOR`/`$VISUAL` now works.
- Up/down history navigation fixed in the TUI.
- Tool printouts now work in the TUI.
- Escape sequence bug in confirmation prompts (`[Y/n]` rendering).
- Choice handling fixes; empty results for `/notes`, `/tools`, `/mcp-tools` now report properly instead of returning empty success.
- Update system checks the `WISEMONKEY_INSTALLED` variable instead of UV environment markers.
- Quality-of-life fixes across the REPL, commands, console, startup output, and TUI.

## Other

- Shell commands now run with `sh` instead of `bash` (installer docs updated to `| sh`).
- Agent accent color changed (`medium_orchid` → `orange3`).
- TUI styles externalized and theme dict reorganized; input widget abstracted so it works in both normal and TUI modes.
- ASCII art credits added.
- Version bump in `pyproject.toml`.
